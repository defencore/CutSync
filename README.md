# CutSync

Монтажна студія, що працює у браузері: багатодоріжковий таймлайн, монтаж відео, окремий звук, синхронізація за звуковою хвилею, корекція зображення та субтитри. Статичний застосунок для **https://cutsync.global.agency** через GitHub Pages.

## Робочий процес

1. При відкритті сайту показується стартова сторінка. Створіть порожній проєкт, відкрийте `.cutsync.json` або явно продовжіть останній збережений проєкт. Демо доступне окремо й не перезаписує ваше локальне збереження.
2. Укажіть назву, формат кадру (16:9, 9:16 або 1:1) та частоту кадрів. Імпортуйте свої матеріали.
3. Клік на картці відкриває оригінал для перегляду. Кнопка **+** або перетягування додає його на шкалу. **Додати нові на шкалу** додає ще не використані матеріали послідовно; відео/фото й аудіо мають окремі доріжки.
4. Виберіть кліп на шкалі, щоб обрізати, перемістити, налаштувати колір і звук. Основні параметри відкриті; додаткові згорнуті. Слайдери дають живий перегляд, одне перетягування — одна дія скасування; текст і числа застосовуються після Enter або виходу з поля.
5. Для синхронізації виберіть еталон і другий кліп, знайдіть збіг, перевірте зміщення та явно застосуйте вирівнювання. За бажанням вимкніть звук другого кліпу.
6. Перевірте послідовність, додайте субтитри та експортуйте відео. Діалог показує точні розміри кадру й доступні браузеру формати. Кнопка експорту доступна після додавання кліпів і відновлення потрібних медіафайлів.
7. Зміни й оригінали автоматично зберігаються в цьому браузері для одного поточного проєкту. Меню **Проєкт** дозволяє завантажити файл монтажу, змінити налаштування або повернутися на старт. Перед створенням іншого проєкту можна завантажити копію попереднього без декодування медіа.

## Можливості

- Імпорт локальних відео, аудіо та зображень; медіатека з прев’ю й звуковими хвилями.
- Відео- й аудіодоріжки, переміщення кліпів, вхідна точка та тривалість, розрізання, вимкнення звуку і видимості доріжок.
- Попередній перегляд композиції з оригінальними файлами.
- Яскравість, контрастність, насиченість, температура, розмиття, масштаб, позиція кадру, поворот, плавне затемнення й виділення ділянки.
- Гучність, нормалізація, компресор, низько- та високочастотні фільтри, бас / високі частоти; зменшення шуму за вибраним зразком.
- Співставлення записів за аудіосигналом. Результат залежить від спільного чутного фрагмента; різний шум, тиша, сильна компресія чи довгі записи можуть потребувати ручного уточнення.
- Ручні субтитри, імпорт SRT / WebVTT та експорт SRT; субтитри впалюються у відео під час експорту.
- Локальне збереження монтажу разом з файлами в IndexedDB. Місце та строк збереження залежать від браузера; очищення даних сайту видаляє проєкт.
- Файл `.cutsync.json` зберігає монтажні рішення, а не вихідні медіафайли. Для перенесення проєкту зберігайте також оригінали й повторно під’єднуйте їх.

## Локальність і формати

Медіафайли не завантажуються на сервер. Canvas, Web Audio та MediaRecorder обробляють їх на пристрої користувача. Після завантаження застосунку робота з файлами не потребує стороннього API чи облікового запису. Демонстраційні зображення постачаються разом із застосунком.

Підтримка конкретних кодеків залежить від браузера й операційної системи. Практичний формат для імпорту — MP4 з H.264 / AAC; також підтримуються доступні браузеру WebM, WAV, MP3 та зображення. Відео може відтворюватися без доступного для декодування аудіопотоку — у такому разі для звуку та синхронізації імпортуйте окремий WAV / MP3.

Експорт відбувається **в реальному часі**: хвилина монтажу потребує близько хвилини роботи. Тримайте вкладку активною до завершення. Застосунок пропонує лише формати, підтримувані `MediaRecorder`: MP4, коли він доступний, або WebM. Наявність MP4 не гарантується в кожному браузері. Файл експорту містить композицію з ефектами, змішаним звуком та субтитрами. Це браузерний редактор, а не повна реалізація DaVinci Resolve: тут немає серверного рендерингу, автоматичного розпізнавання мовлення, RAW-декодування чи професійного керування кольором.

Для довгих проєктів і великих файлів потрібен достатній обсяг оперативної пам’яті та вільного місця. Рекомендовано актуальний настільний Chrome або Edge; доступні формати перевіряються під час експорту.

## GitHub Pages і домен

1. Завантажте репозиторій у `defencore/CutSync`, гілка `main`.
2. У **Settings → Pages → Build and deployment → Source** виберіть **GitHub Actions**.
3. У **Settings → Pages → Custom domain** задайте `cutsync.global.agency`.
4. У DNS-зоні `global.agency` створіть CNAME: `cutsync` → `defencore.github.io` (без протоколу та шляху).
5. Дочекайтеся перевірки DNS і випуску сертифіката GitHub, потім увімкніть **Enforce HTTPS**.

Workflow `.github/workflows/pages.yml` запускає перевірки та збірку для pull request; після push у `main` публікує `dist/` через офіційні GitHub Pages Actions. `public/CNAME` також входить у збірку, але за публікації через Actions **не замінює** налаштування домену у Settings / API. DNS і HTTPS налаштовуються на стороні власника домену та GitHub.

Офіційні довідки: [GitHub Pages Actions](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages), [власний домен](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site), [MediaRecorder](https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder).

## Керування монтажем

- Перемикач **EN / UA** у верхній панелі змінює мову інтерфейсу; вибір зберігається у браузері. Коментарі в коді написані англійською.
- Кнопка **+ Додати доріжку / + Add track** над шкалою додає відео- або аудіодоріжку. Назва доріжки та кнопка **…** відкривають перейменування й видалення. Видалення можна скасувати.
- Для аудіокліпу в інспекторі доступне поле **Зміщення, с / Offset, s**. `−1.5` запускає звук раніше нуля, `+2` затримує початок на дві секунди. Частина від’ємного кліпу до нуля пропускається в перегляді й експорті.
- Звук відеокліпу можна відокремити на аудіодоріжку кнопкою **Відокремити звук / Detach audio**.
- Курсор можна перетягувати за всю вертикальну лінію, вести по лінійці або переставляти кліком у порожній ділянці. Під час перетягування відтворення тимчасово призупиняється і відновлюється після відпускання. Точний час можна ввести у поле секунд під таймкодом.
- Налаштування кольору, звуку, зміщення та доріжок оновлюються без зупинки відтворення. Поки складне очищення перераховується, грає попередній звуковий мікс; після обробки він замінюється в поточній позиції.
